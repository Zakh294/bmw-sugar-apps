# База камер

**Джерело:** офіційний «Перелік приладів контролю» патрульної поліції,
https://patrolpolice.gov.ua/automatic_fixation/informatsiya-pro-vstanovleni-kaf/ — таблиця з індексом дороги, регіоном, кілометром, місцем, обмеженням швидкості і GPS-координатами. Завантажено 18–19.11.2026, 426 комплексів (з 20.08.2026 поліція повідомляла саме про 426).

| Файл | Для чого |
|---|---|
| `cameras.json` | основний: `id, lat, lon, limit, road, km, region, place, type` (`highway` / `city`) |
| `cameras.geojson` | GIS, веб-мапи, OSM |
| `cameras.csv` | таблиця, Google My Maps (UTF-8 з BOM, щоб Excel показав кирилицю) |
| `cameras.kml` | Google My Maps / Earth, по папці на регіон, колір значка за лімітом |
| `cameras.gpx` | OsmAnd, Organic Maps, Garmin — точки маршруту |
| `osm_check.json` | звірка кожної точки з OpenStreetMap (найближча дорога, місто, область) |

## Що виправлено при імпорті

- Три рядки на сайті записані з десятковими комами («50, 769657767, 25, 357070027» — Луцьк, Конякіна 18-А; Львів, Кульпарківська 93; Рівне, Соборна 416). Їх прочитано як 50.769657767, 25.357070027 і т. д.
- Індекси доріг записані то латиницею, то кирилицею (`M-06` / `М-06`), приведено до кирилиці.

## Звірка з OpenStreetMap (`tools/speedcam_ua/verify_osm.py`)

Кожну точку перевірено зворотним геокодуванням Nominatim:
- **426 з 426** лежать на дорозі (найближчий об'єкт OSM — `highway`);
- **усі 197 міських камер** лежать у своєму місті;
- 17 з 229 «трасових» не мають області в OSM-адресі: 5 стоять на межі з Києвом (Столичне шосе, Гостомельське шосе), 12 — у Волинській області, де в OSM порожнє поле області. Це не помилки координат.

## Чого в базі немає

- **Напрямку контролю**: на сайті його немає. Частину напрямків можна взяти з новин МВС («у напрямку м. …»), можливе доповнення.
- **Пересувних засобів** («Фантоми», TruCam) — у списку лише стаціонарні комплекси.
- Камер на тимчасово окупованих територіях та в областях, де йдуть бойові дії: за даними поліції, там прилади до системи не підключено.

## Як потрапляє в додаток

Додаток бере не ці файли, а `apps/speedcam_ua/packs/ua.json`. Його будує `tools/speedcam_ua/build_packs.py` з `cameras.json` разом із базами Європи й США з OpenStreetMap. Щомісяця робочий процес GitHub ([camera-packs.yml](../../.github/workflows/camera-packs.yml)) заново завантажує список поліції, перебудовує ці файли й бази, а машина підтягує ті, що змінилися.
